### **User Story 1: Conversational AI Querying & Avatar Audio Response**

* **User Story:** As an AI student, I want to ask questions via text or voice and hear the avatar speak the answer using text-to-speech so that I can get quick, natural, hands-free answers to my campus questions.  
* **Acceptance Criteria:**  
  * Displays a prominent interactive avatar container with visual audio-wave or speaking indicators while speaking.  
  * Provides a clear text input box alongside a microphone button for voice queries.  
  * Includes audio controls (Mute, Pause, and Playback Speed: $1\\times$, $1.25\\times$, $1.5\\times$).  
    

### **User Story 2: Source Verification & Official Links (RAG Transparency)**

* **User Story:** As a student, I want to see official college source links cited alongside the AI’s answer so that I can verify the information is accurate and navigate directly to official college pages.  
* **Acceptance Criteria:**  
  * Displays clickable "Source Chips" or cards under each generated answer (e.g., *Source: Centennial College Financial Aid Page*).  
  * Clicking a source opens the official college webpage in a new browser tab.  
  * Shows a confidence or verification badge indicating the info came directly from the verified college knowledge base.  
    

### **User Story 3: Guided Quick-Topic Cards**

* **User Story:** As a first-time user, I want to click pre-set quick topic buttons (e.g., Financial Aid, OSAP, Registration, IT Support) so that I can get instant help without having to type out full questions.  
* **Acceptance Criteria:**  
  * The main landing page features clear category chips or cards for high-traffic student topics.  
  * Clicking a topic populates sample queries or immediately triggers the virtual receptionist.  
  * Includes a search bar with auto-suggest prompts for common campus inquiries.  
    

### **User Story 4: Multi-Modal Chat History & Transcript View**

* **User Story:** As an AI student, I want to read the written text transcript alongside the avatar’s audio so that I can copy important dates, emails, or instructions for later.  
* **Acceptance Criteria:**  
  * Side-by-side or collapsible transcript panel displaying the full conversation history.  
  * A "Copy Answer" button on every response block.  
  * Option to clear chat history or start a fresh session.  
    

### **User Story 5: Avatar Personalization & Accessibility Controls**

* **User Story:** As an AI student with accessibility preferences, I want to toggle closed captions, adjust text size, or switch the avatar on/off so that I can comfortably use the interface regardless of my environment.  
* **Acceptance Criteria:**  
  * Accessibility toolbar with options to toggle Closed Captions (CC), adjust font size, or enable High Contrast mode.  
  * Toggle button to minimize or hide the 3D/2D avatar video window and switch to text-only mode for slow internet connections.
